# Contributing to EorbahAPI

Thank you for your interest in contributing to EorbahAPI.

This project is currently under active development, and contributions are welcome as the framework evolves.

## How to contribute

- Open an issue if you want to request a feature, report a bug, or discuss improvements.
- Submit a pull request with a clear description of the changes.
- Include tests for any new functionality or bug fixes.
- Keep code style consistent with the existing project conventions.

## Development setup

1. Fork the repository.
2. Clone your fork locally.
3. Run `composer install`.
4. Create a feature branch.
5. Make your changes and add tests.
6. Run `./vendor/bin/phpunit tests`.
7. Open a pull request.

## Notes

- The project is still under development, so some APIs and internals may change.
- Please keep contributions focused, small, and easy to review.
