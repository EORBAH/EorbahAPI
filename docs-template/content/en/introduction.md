# Build documentation people actually enjoy reading

This template gives you a clean, responsive and **extensible** base for
technical documentation. Content (Markdown), theme (CSS variables) and
behavior (JS) stay separate.

:::callout{type="info" title="Everything is config-driven"}
`config/site.json` defines the brand, languages, themes and footer.
`config/nav.json` defines pages, categories and prev/next order.
:::

## What you get

- A 100% CSS-variable theme (`css/root.css`), with 3 themes ready to use.
- A language switcher and a theme switcher in the header.
- A contextual sidebar **and** a full site menu, clearly separated.
- Automatic previous/next navigation at the bottom of every page.
- A fully customizable footer (links, social, contact, solutions).
- A plugin system to extend Markdown itself.
