# Construisez une documentation qui ne donne pas envie de fuir

Ce template fournit une base propre, responsive et **extensible** pour générer
une documentation technique. Le contenu (Markdown), le thème (variables CSS)
et les comportements (JS) restent séparés.

:::callout{type="info" title="Tout est piloté par la config"}
`config/site.json` définit la marque, les langues, les thèmes et le footer.
`config/nav.json` définit les pages, les catégories et l'ordre précédent/suivant.
:::

## Ce que tu obtiens

- Un thème 100% variables CSS (`css/root.css`), avec 3 thèmes déjà prêts.
- Un sélecteur de langue et un sélecteur de thème dans le header.
- Une sidebar contextuelle **et** un menu complet du site, bien séparés.
- Une navigation précédent/suivant automatique en bas de chaque page.
- Un footer personnalisable (liens, réseaux sociaux, contact, solutions).
- Un système de plugins pour étendre le Markdown.
